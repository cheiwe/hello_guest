# Акт 1 — блокаут дома соседа

Уровень: `/Game/Maps/L_Act1`. Собирается скриптом [Scripts/Editor/create_act1_house.py](../Scripts/Editor/create_act1_house.py)
(повторный запуск пересобирает уровень с нуля). Всё, что ниже, — значения из скрипта; меняем там и пересобираем.

Источник планировки: раздел 5.2 [PLAN.md](PLAN.md) и концепты в `SourceArt/Concept/`
(`Yard_01..03` — двор, `Hallway_01/02/simple` — холл).

## Как пересобрать

В редакторе: **Tools → Execute Python Script…** → `Scripts/Editor/create_act1_house.py`.

Из терминала при открытом редакторе (включён Python Remote Execution, Project Settings → Plugins → Python):

```
py Scripts/Tools/ue_run.py Scripts/Editor/create_act1_house.py
```

## Оси и цвета

- 1 единица = 1 см. Фасад смотрит на **−X** (улица), **+X** — к заднему двору, **Y < 0** — левая сторона, если стоять лицом к дому.
- Дом: X 0…1600, Y −500…500 (16 × 10 м). Координаты комнат — по осям стен, толщина стен и перекрытий 20 см.
- Цвета блокаута: серый — стены, бежевый — фасад, коричневый — полы и лестницы, тёмный — крыша,
  жёлтый — карниз и выступы для паркура, синий — мебель/укрытия, красный — опасность и подсказки
  (ложная ступенька, кровавые цифры, картина, слабый пол, шпиль, пожарная лестница-заглушка).

## Планировка

### Улица и двор

- Через улицу — дом игрока, точка возрождения `HomeSpawn`.
- Задний двор за дощатым забором 2,5 м, калитка в правом заборе. В дальнем левом углу под деревом — заколоченный туалет
  (лом, внутри антенна для доп. квеста). Ящики, бочки, поленница — укрытия.
- У задней стены — загон из рабицы вокруг разбитого окна кладовой (из двора в загон не попасть, только изнутри через окно).
- Рядом с загоном, снаружи — пожарная лестница к окну детской на 2-м этаже.

### 1-й этаж

| Комната | Где | Что внутри |
|---|---|---|
| Холл | узкий (1,5 м) по центру от входа до X 1000, дальше расширение 3,5 м | вешалка, столик с телефоном |
| Кладовка (слева у входа, запретная для Гостя) | X 0…550 | стол с **ломом** |
| Кабинет (справа у входа, запретный) | X 0…550 | стол и постамент для ребуса с картиной, книжный шкаф; **красный ключ — заглушка** на столе |
| Кухня-столовая (слева) | X 550…1250 | **маленький ключ** от двери наверху; спуск в подвал со щитком; боковая дверь во двор |
| Лестничный холл (справа) | X 550…1250 | широкий проём из холла **заколочен** (лом); лестница на 2-й этаж; окно во двор |
| Кладовая (сзади слева) | за кухней | разбитое окно в загон |
| Комната за дверью на цепях (сзади) | X 1250…1600 | длинная лестница в закрытый подвал, **ложная ступенька** (8-я) |

Дверь на цепях — в торце холла, по бокам два узких окна в комнату с лестницей. Замки: красный, синий, жёлтый,
зелёный под паутиной (ножницы).

### Подвалы

- **Подвал со щитком** — под кухней: щиток (предохранитель), шкаф рядом (будущая ловушка), бойлер.
- **Закрытый подвал** — под задней комнатой и лестничным холлом: пульт с мониторами, кассеты. Тёмная зона.

### 2-й этаж

| Комната | Что внутри |
|---|---|
| Площадка за дверью «маленький ключ» (сзади справа) | **ножницы**, лестница на чердак |
| Коридор (за **лентой**) | картина с усатым мужчиной, кровавый след |
| Комната с лампочками (спереди слева) | 4 патрона на двух противоположных стенах, 4 лампочки, кровавые цифры. Тёмная |
| Комната с золотыми яблоками (слева) | картины, шкаф; справа от картин — **заколоченная** дверь в детскую |
| Детская (сзади слева) | **предохранитель**, ящик с игрушками, окно к пожарной лестнице |
| Комната с сейфом (справа) | сейф; **синий ключ — заглушка** на сейфе |
| Спальня (спереди справа) | кровать, шкаф — укрытия |

### Чердак и крыша

- Чердак: радиостанция у заднего фронтона (**жёлтый ключ — заглушка**), слабый пол перед ней,
  встроенный шкаф, **заколоченный** (лом), внутри **зелёный ключ**.
- Башенка на левом скате: из чердака низкий проход (пригнуться), внутри ящик и площадка до 7,5 м, дыра наружу.
- Путь к шпилю: дыра → карниз вдоль левого свеса → за угол на передний фронтон → 6 выступов вверх по фронтону
  (каждый — один прыжок, 62 см) → конёк → шпиль с креплением для антенны.

## Гость

- Фаза 0: задняя часть дома (расширение холла, кухня, кладовая), подвал со щитком, двор. Ко входу не подходит,
  во двор ходит через боковую дверь кухни. Фаза 1: лестничный холл, середина холла, площадка 2-го этажа;
  фаза 2: остальной 2-й этаж. Точки, до которых нет полного пути (за досками), пропускаются.
- Сторона улицы игрока и его двор — безопасная зона (`HGSafeZone`): там Гость бросает погоню, проигрывает
  анимацию досады (`GuestA_Guest_LostPlayer`) и возвращается к патрулю; шумы оттуда не слышит.
- Кладовка и кабинет — запретные зоны (`HGNavArea_GuestRestricted`), заглядывает туда с фазы 1.
- Навигация проверена: при снятых препятствиях Гость доходит до всех комнат, обоих подвалов, двора и улицы.
  На чердак не ходит — лестница 1 м слишком узкая для его навмеша (для чердака это допустимо).

## Заглушки и что не сделано

- Головоломки (картина-ребус, сейф, радиостанция) не реализованы: ключи лежат открыто на месте будущей награды.
- Лестница на чердак стоит всегда; по плану она опускается после рубильника. Рубильника нет: щиток сразу ставит флаг `Puzzle.Breaker`.
- Пожарная лестница — декорация: лазания пока нет. Шаг боком по карнизу тоже не сделан, карниз — обычный уступ.
- Ловушки (ложная ступенька, слабый пол, балка, шкаф) только обозначены цветом.
- Слуховых окон с концептов в блокауте нет; дом игрока — коробка без интерьера.
- Прыжки по выступам к коньку посчитаны по высоте прыжка (~74 см), но вручную в игре ещё не пройдены.

## Арт-уровень L_Act1_Art (ночь, гроза, финал)

`/Game/Maps/L_Act1_Art` собирает [Scripts/Editor/create_act1_art.py](../Scripts/Editor/create_act1_art.py): запускает этот блокаут в свою карту
(весь геймплей тот же), ставит на кубы материалы MI_Arch_* с мировыми UV, обшивку стен, потолки, доски под крышей,
меняет синие блоки на модели (блоки остаются невидимыми коллизиями), улицу, дом игрока, фургон, дождь,
грозу (`AHGStorm`: молнии, гром, дождь) и финал (`AHGFinaleTrigger` + `LS_Act1_Finale`). Меняем планировку здесь,
потом перезапускаем оба скрипта.

Проверка в игре: консоль `HGLightning 0` — удар молнии, `HGFinale` — финальная сцена сразу.
