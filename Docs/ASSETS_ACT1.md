# Акт 1 — ассеты по концептам

Как делаем (без платных сервисов):

- **H** — Hunyuan3D-2 локально на RTX 4090 (`D:\AI\Hunyuan3D-2`), картинка → 3D. Для органики и сложных форм.
  Текстуры пока не генерируются (нужен CUDA Toolkit) — красим проекцией концепта и материалами в Blender.
- **B** — моделирую сам в Blender кодом: архитектура, мебель, техника, всё «твёрдое».
- **P** — PolyHaven (CC0): текстуры (дерево, штукатурка, кирпич, бетон, черепица, асфальт, трава, ржавый металл) и HDRI заката.

Исходники: `SourceArt/Models/<Категория>/*.blend` → экспорт FBX рядом → импорт в `/Game/Art/<Категория>/`.
Масштаб: 1 единица Blender = 1 м, при экспорте ×100 → см. Ось вперёд — +X, как у персонажей.

## Порядок

1. **Пилот** — холл 1-го этажа (Hallway_01/02): модульные стены/пол/потолок, двери с наличниками, дверь на цепях
   с 4 замками и паутиной, вешалка, столик с телефоном, бра, картины. Плюс Витёк (H) и туалет (H) — проверка Hunyuan.
2. Экстерьер (Street_Example, Yard_01-03): фасад, крыша с черепицей, башенка со шпилем, крыльцо, заборы (дощатый,
   рабица, штакетник), фургон, деревья, мусор двора, дом игрока.
3. Комнаты по одной (ниже), затем подвалы и чердак.
4. Сборка уровня `L_Act1_Art` из ассетов по планировке блокаута, свет по концептам.
5. Финальная сцена с Витьком.

## Финальная сцена (Витёк)

Последняя комната — закрытый подвал. Игрок входит → Витёк сидит за пультом, разворачивается к игроку и кричит
«Анита! Я же просил никого не пускать во время стрима!» → смягчается: «Ну ладно, иди покажу кое-что странное» →
на мониторе запускается запись: Гость тащит соседа в машину.

Нужно: анимации Витька (сидит → поворот → крик → смягчение → жест), субтитры RU/EN, озвучка (позже — решить, чем),
ролик записи (Level Sequence: Гость + Сосед + фургон, рендер на экран монитора через Media/Render Target).
