# Hello Guest

Фанатское продолжение Hello Neighbor на Unreal Engine 5 (C++). Дизайн-план: [Docs/PLAN.md](Docs/PLAN.md).

**Статус:** каркас проекта (milestone 1). Системы написаны на C++, игра запускается на сером
тестовом уровне без единого ассета. Модели, звуки, UI-меню и головоломки Акта 1 — следующие этапы.

## Требования

- Unreal Engine **5.8**. Если стоит другая версия: ПКМ по `HelloGuest.uproject` →
  *Switch Unreal Engine version*.
- Windows: Visual Studio 2022 с компонентом «Game development with C++».
  Linux: clang из комплекта движка.
- Git LFS (`git lfs install`) — все `.uasset`, `.umap`, текстуры, модели и звуки хранятся в LFS.

## Первый запуск

Подробная пошаговая инструкция: [Docs/OPEN_PROJECT.md](Docs/OPEN_PROJECT.md).

1. Клонировать репозиторий, выполнить `git lfs pull`.
2. Открыть `HelloGuest.uproject`. Движок предложит собрать модуль `HelloGuest` → **Yes**.
   (Либо ПКМ по `.uproject` → *Generate Visual Studio project files* и собрать `HelloGuestEditor` в VS.)
3. В редакторе: **Tools → Execute Python Script…** → `Scripts/Editor/create_test_map.py`.
   Скрипт создаст и сохранит уровень `/Game/Maps/L_Sandbox` (серые коробки, Гость, предметы, двери).
   Пока уровня нет, редактор при старте предупредит, что карта не найдена, — это нормально.
4. Нажать **Play**.

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Движение | W A S D | Левый стик |
| Обзор | Мышь | Правый стик |
| Прыжок | Space | A / ✕ |
| Присесть (тихий шаг) | Ctrl или C | B / ○ |
| Бег | Shift (удерживать) | Нажатие левого стика |
| Взаимодействие / взять / отпустить предмет | E | X / □ |
| Бросить предмет / использовать выбранный | ЛКМ | RT |
| Выбор предмета в инвентаре | Колесо мыши | LB / RB |
| Пауза | Esc или P | Start / Options |

Подсказки на экране сами переключаются между клавиатурой и геймпадом по последнему устройству ввода.
Переназначение клавиш появится вместе с меню настроек.

## Консольные команды (клавиша `~`)

| Команда | Что делает |
|---|---|
| `HGSave` | Ручное сохранение в текущий слот (не работает во время погони) |
| `HGLoad 1` | Загрузить слот 1 (берётся самое новое: ручное или автосохранение) |
| `HGNewGame 2` | Новая игра в слоте 2 |
| `HGSlots` | Список слотов: дата, % прохождения, время в игре |
| `HGLanguage ru` / `HGLanguage en` | Сменить язык на лету |
| `HGGive KeyRed` | Выдать предмет (отладка) |
| `HGFlag Item.KeyYellow` | Установить флаг прогресса (отладка, например чтобы поднять фазу Гостя) |

## Что уже работает

- **Игрок:** ходьба, бег, присед, прыжок; урон от падения (2 роста — оглушение, 3 роста — смерть);
  шум шагов (присед бесшумен); перенос и бросок физических предметов; инвентарь (до 12 видов предметов).
- **Взаимодействие:** подбор предметов, препятствия (доски — лом, лента/паутина — ножницы), двери с
  любым числом замков и условиями («зелёный замок после трёх цепей», «замок под паутиной»), гнёзда
  для предметов (предохранитель, лампочки, антенна), тёмные зоны для пряток, шумные бросаемые предметы.
- **Гость:** зрение и слух (AI Perception), тревога 0–100, патруль → проверка шума → поиск → погоня;
  не заходит в «запретные» комнаты у входа, пока не гонится за игроком; фазы активности по прогрессу;
  проходит сквозь двери и распахивает незапертые; оглушение, замедление (ловушки) и «растворение»
  (космическое ружьё).
- **Смерть:** скример (случайный звук из списка), респаун у дома с сохранением инвентаря.
- **Сохранения:** 3 слота, в каждом ручное сохранение и автосохранение при любом шаге прогресса;
  версия формата для миграции; состояние дверей, препятствий и предметов на уровне.
- **Настройки:** язык (RU/EN, переключение без перезапуска), чувствительность мыши и геймпада,
  инверсия, вибрация, субтитры, громкости; графика — стандартные пресеты Low/Medium/High/Epic.

Все числа (скорости, высоты падений, радиусы зрения и слуха, тайминги) настраиваются в
**Project Settings → Game → Hello Guest** без перекомпиляции.

## Импорт моделей и анимаций

- Формат: **FBX** (лучше всего для Unreal) или glTF/GLB. Модель и анимации на одном скелете.
- Исходники класть в `SourceArt/Characters/<Имя>/`, импортировать в `Content/Characters/<Имя>/`.
- Масштаб: 1 единица = 1 см, персонаж стоит на нуле, смотрит вдоль оси X.
- Гость и сосед: положить `SourceArt/Characters/Guest/Guest.glb` и `SourceArt/Characters/Neighbor/Neighbor.glb`,
  затем в редакторе **Tools → Execute Python Script…** → `Scripts/Editor/import_characters.py`.
  Скрипт импортирует модели с анимациями и сам назначит Гостю модель и анимации
  (Project Settings → Game → Hello Guest → Guest | Model). Если модель повёрнута боком,
  поменяйте там `Character Mesh Yaw Offset` (−90 / 0 / 90 / 180).

## Резервные копии

- Основная копия — этот репозиторий на GitHub. Код и ассеты коммитятся после каждого этапа.
- Перед крупными изменениями создаётся ветка-снимок `backup/<дата>-<описание>` (её никто не меняет);
  вернуться к ней: `git checkout backup/2026-10-19-skeleton`.
- **Важно про LFS:** бесплатный лимит Git LFS на GitHub — 1 ГБ хранилища и 1 ГБ трафика в месяц.
  Проект с моделями и звуками быстро его превысит. Варианты: докупить Data Pack на GitHub (Settings →
  Billing) или дополнительно хранить папку проекта на внешнем диске / облаке.
- Локально: Unreal сам делает автосохранения в `Saved/Autosaves` и бэкапы в `Saved/Backup`.
